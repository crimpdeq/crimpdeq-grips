# Printing

Print all 14 parts in PETG (HF) with these settings:

| Setting | Value |
|---|---|
| Layer height | 0.2 mm |
| Walls | 5 |
| Infill | 35% cubic, or more |
| Plate | Textured PEI |
| Supports | Frame only |
| Brim | 5 mm on the frame and the ring, middle and index walls |

The frame stands 111 mm tall, and without a brim a wall can lift on its first layers and the rest
of it prints as spaghetti. Wash the plate with dish soap before printing.

Each release also has a Bambu Studio project for the Bambu Lab A1 per grip and hand
(`crimpdeq-grips-<grip>-<hand>.3mf`) with all parts on one plate and these settings.

The STLs are already in their print pose: frame, walls and rollers on their pinky-side face with the
pin holes vertical, pins lying on their flat, the post on its chamfered side. In this pose the walls
need no supports, as in the original design.
